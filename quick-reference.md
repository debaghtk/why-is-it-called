## 🔍 Common Prefixes & Suffixes

### Understanding Word Parts
- **-ware** (software, hardware) = "goods/products"
- **-tion** (function, recursion) = "action/process"
- **cyber-** = "computer/internet related"
- **meta-** = "about/beyond"
- **multi-** = "many/multiple"
- **inter-** = "between"
- **sub-** = "under/below"

## 🎯 Most Commonly Confused Terms

### Stack vs Queue
- **Stack**: Like plates - add/remove from top (LIFO)
- **Queue**: Like a line - enter at back, exit at front (FIFO)

### Cache vs Buffer
- **Cache**: Hidden storage for speed (permanent until cleared)
- **Buffer**: Temporary storage for smoothing data flow

### Function vs Method
- **Function**: Standalone code block
- **Method**: Function that belongs to a class/object

### Library vs Framework
- **Library**: Tools you use (you're in control)
- **Framework**: Structure that uses your code (it's in control)

## 💡 Memory Tips

1. **People Names**: Algorithm (Al-Khwarizmi), Bug (Grace Hopper)
2. **Physical Objects**: Stack (plates), Web (spider), Cookie (fortune)
3. **French Origins**: Cache (hide), Queue (tail), Buffer (cushion)
4. **Latin Origins**: Memory (remember), Variable (changeable), Function (perform)
5. **Actions**: Debug (remove bugs), Compile (gather), Hash (chop/mix)

## 🎓 Study Strategies

### For Beginners
1. Start with physical analogies (stack = plates)

3. Connect to similar words in your language
4. Use visual associations
