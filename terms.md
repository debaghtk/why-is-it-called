## A

### Algorithm
**Origin**: Named after **Al-Khwarizmi** (780-850 CE), a Persian mathematician whose name was Latinized to "Algorithmus"

**Meaning**: A step-by-step procedure for solving a problem

**Why this makes sense**: Just like Al-Khwarizmi created systematic methods for solving mathematical problems, algorithms are systematic methods for solving computational problems.

**Example**: A recipe is an algorithm for cooking - it has clear steps that lead to a desired result.

---

### API (Application Programming Interface)
**Origin**: **Interface** comes from Latin "inter" (between) + "facies" (face/surface)

**Meaning**: A way for different software programs to communicate with each other

**Why this makes sense**: An interface is literally the "face between" two things - the boundary where they meet and interact.

**Example**: A restaurant menu is like an API - it shows you what you can order (available functions) without showing how the kitchen works (implementation details).

---

## B

### Bug
**Origin**: Coined by **Grace Hopper** in 1947 when an actual moth was found trapped in a computer relay

**Meaning**: An error or flaw in software code

**Why this makes sense**: Just like insects can get into machinery and cause problems, code errors can "get into" your program and cause it to malfunction.

**Example**: "There's a bug in the login system" means there's an error preventing users from logging in properly.

---

### Buffer
**Origin**: From Old French "buffe" meaning "a blow" - originally a cushion that absorbs impacts

**Meaning**: A temporary storage area for data

**Why this makes sense**: Just like a physical buffer absorbs shock, a data buffer absorbs the "shock" of different data processing speeds.

**Example**: When watching a video online, buffering means storing some video data ahead of time so playback doesn't stop.

---

## C

### Cache
**Origin**: From French "cacher" meaning "to hide"

**Meaning**: A high-speed storage area that keeps frequently used data readily available

**Why this makes sense**: Cache "hides away" frequently needed data in a quickly accessible place, just like hiding valuables in an easy-to-reach secret spot.

**Example**: Your browser cache hides/stores website images so they load faster next time you visit.

---

### Cookie
**Origin**: Named after **fortune cookies** - small packages that contain hidden information

**Meaning**: Small pieces of data stored by websites on your computer

**Why this makes sense**: Like fortune cookies contain hidden messages, web cookies contain hidden information about your browsing session.

**Example**: A shopping website uses cookies to "remember" what items you put in your cart.

---

### Compile
**Origin**: From Latin "compilare" meaning "to plunder/gather together"

**Meaning**: To translate source code into executable machine code

**Why this makes sense**: The compiler "gathers together" all your code files and transforms them into something the computer can run.

**Example**: Writing in Java and compiling creates a .class file that the computer can execute.

---

## D

### Daemon
**Origin**: From **Maxwell's demon**, a thought experiment about a helpful entity that sorts molecules

**Meaning**: A background process that runs continuously without user interaction

**Why this makes sense**: Like Maxwell's theoretical demon that works tirelessly in the background, daemon processes work behind the scenes to keep systems running.

**Example**: A print daemon waits in the background and handles print jobs when they come in.

---

### Database
**Origin**: "Data" (Latin "datum" = something given) + "base" (foundation/storage place)

**Meaning**: An organized collection of structured information

**Why this makes sense**: It's literally a "base" or foundation where you store your "data" in an organized way.

**Example**: A library catalog is like a database - it organizes information about books so you can find what you need.

---

### Debug
**Origin**: The opposite of creating a "bug" - removing the problem

**Meaning**: The process of finding and fixing errors in code

**Why this makes sense**: If bugs are problems, then debugging is removing those problems from your code.

**Example**: When your app crashes, you debug by finding what's causing the crash and fixing it.

---

## F

### Firewall
**Origin**: From physical **fire walls** in buildings that prevent fire from spreading

**Meaning**: A security system that monitors and controls network traffic

**Why this makes sense**: Just like physical firewalls stop fire from spreading between rooms, network firewalls stop malicious traffic from spreading into your system.

**Example**: A home router's firewall blocks hackers from accessing your personal devices.

---

### Function
**Origin**: From Latin "functio" meaning "performance/execution of a task"

**Meaning**: A reusable block of code that performs a specific task

**Why this makes sense**: Functions literally "perform" or execute specific tasks in your program.

**Example**: A calculator has an "add" function that performs the task of adding two numbers.

---

## H

### Hash
**Origin**: From cooking term meaning "to chop up and mix together"

**Meaning**: A function that converts input data into a fixed-size string of characters

**Why this makes sense**: Hashing "chops up" your input data and "mixes" it to create a unique fingerprint.

**Example**: Password hashing "chops up" your password into an unrecognizable string for security.

---

### Heap
**Origin**: From Old English "heap" meaning "a pile of things"

**Meaning**: A region of memory used for dynamic memory allocation

**Why this makes sense**: Memory in the heap is allocated in a somewhat random, "piled up" manner, like objects in a heap.

**Example**: When you create objects in Java, they're stored in the heap memory area.

---

## I

### Interface
**Origin**: Latin "inter" (between) + "facies" (face/surface)

**Meaning**: A shared boundary where different systems meet and interact

**Why this makes sense**: It's literally the "face between" two different systems - the point where they connect.

**Example**: A steering wheel is the interface between you and your car's steering system.

---

## L

### Library
**Origin**: From Latin "librarium" meaning "bookcase/collection of books"

**Meaning**: A collection of pre-written code that you can use in your programs

**Why this makes sense**: Just like a library contains books you can borrow and use, a code library contains code you can include and use.

**Example**: A math library contains pre-written functions for calculations like square root or trigonometry.

---

### Loop
**Origin**: From Middle English "loupe" meaning "a fold/bend that crosses itself"

**Meaning**: A sequence of instructions that repeats until a condition is met

**Why this makes sense**: The execution path literally "loops back" on itself, like a physical loop shape.

**Example**: A for loop repeats a block of code a specific number of times.

---

## M

### Memory
**Origin**: From Latin "memoria" meaning "the ability to remember"

**Meaning**: Computer storage where data and instructions are kept

**Why this makes sense**: Computer memory "remembers" information, just like human memory.

**Example**: RAM is temporary memory that remembers what programs you're currently running.

---

## P

### Protocol
**Origin**: From Greek "protokollon" meaning "first sheet glued to a manuscript" (containing official procedures)

**Meaning**: A set of rules governing how data is transmitted between devices

**Why this makes sense**: Just like diplomatic protocols define how officials should interact, network protocols define how computers should communicate.

**Example**: HTTP is a protocol that defines how web browsers and servers should exchange information.

---

## Q

### Queue
**Origin**: From French "queue" meaning "tail" (people standing in a line like a tail)

**Meaning**: A data structure where items are processed in the order they were added (first-in, first-out)

**Why this makes sense**: Just like people in a queue/line are served in the order they arrived, data in a queue is processed in arrival order.

**Example**: Print jobs are handled in a queue - first document sent gets printed first.

---

## R

### Recursion
**Origin**: From Latin "recursus" meaning "a running back/return"

**Meaning**: A function that calls itself to solve smaller versions of the same problem

**Why this makes sense**: The function literally "runs back" to itself, like returning to the same place.

**Example**: To count all files in a folder and its subfolders, you recursively count files in each subfolder.

---

## S

### Stack
**Origin**: From Old Norse "stakkr" meaning "a pile of things placed on top of each other"

**Meaning**: A data structure where items are added and removed from the same end (last-in, first-out)

**Why this makes sense**: Just like stacking plates - you add to the top and remove from the top.

**Example**: Your browser's back button uses a stack - the last page you visited is the first one you return to.

---

### Server
**Origin**: From Latin "servire" meaning "to serve"

**Meaning**: A computer that provides services to other computers

**Why this makes sense**: A server literally "serves" other computers by providing them with data, applications, or other services.

**Example**: A web server serves web pages to your browser when you visit a website.

---

## T

### Thread
**Origin**: From Old English "thrǣd" - the strand used in weaving

**Meaning**: A lightweight subprocess that can run concurrently with other threads

**Why this makes sense**: Just like threads are woven together to create fabric, program threads work together to create the complete application.

**Example**: A music app might use one thread for playing music and another thread for updating the display.

---

### Token
**Origin**: From Old English "tacen" meaning "sign/symbol"

**Meaning**: A piece of data that represents something else (like user authentication or access rights)

**Why this makes sense**: Like a token at an arcade represents money you can spend, security tokens represent your right to access resources.

**Example**: After logging in, you get an authentication token that proves you're allowed to access your account.

---

## V

### Variable
**Origin**: From Latin "variabilis" meaning "changeable"

**Meaning**: A storage location with a name that can hold different values

**Why this makes sense**: Variables are literally "changeable" - you can put different values in them throughout your program.

**Example**: A variable called "score" might start at 0 and change as the player earns points.

---

### Virus
**Origin**: From Latin "virus" meaning "poison/slimy liquid" (biological virus concept)

**Meaning**: Malicious software that replicates itself and spreads to other systems

**Why this makes sense**: Computer viruses behave like biological viruses - they spread from host to host and can cause damage.

**Example**: An email virus spreads by sending copies of itself to contacts in your address book.

---

## W

### Web
**Origin**: From Old English "webb" meaning "spider's web" - an interconnected network

**Meaning**: The World Wide Web - an interconnected system of web pages and resources

**Why this makes sense**: Like a spider's web connects many points together, the web connects websites and resources across the globe.

**Example**: Clicking links takes you through the web from one connected page to another.

---

### Wizard
**Origin**: From Middle English "wisard" meaning "wise person" - someone who guides you through complex tasks

**Meaning**: A user interface that guides users through a complex process step-by-step

**Why this makes sense**: Like a wise wizard guides a hero through a quest, software wizards guide users through complex setup processes.

**Example**: A setup wizard helps you install software by asking questions and guiding you through each step.
